# 섹션 컨테이너 일관성 감사 (R2)

2026-11-10 제보 "홈 랭킹은 카드인데 공지사항은 구분선만 있다. app 전반의 통일성 검토 필요"에서 시작했다. 사용자 라우트(관리자 제외)를 로컬 개발 서버(로그인 `dev-fan-3`, 390·1440)에서 열어 섹션 컨테이너를 확인한 결과다. 로컬 데이터라 일부 화면은 비어 있거나 불러오기 실패 상태이며, 그런 구역은 틀만 확인했다.

## 규칙 R2

- 한 화면의 같은 역할 구역은 같은 컨테이너를 쓴다. 기준은 `FanSurface`(흰 면, 1px `--color-line`, 반경 12, 그림자 0 — DESIGN.md 카드 외곽)이다.
- 행으로 이어진 목록(공지·게시글·랭킹·알림)은 `FanSurface appearance="list"` 안에 둔다. 행은 자기 좌우 여백(16)과 구분선을 갖고 마지막 행의 구분선은 카드 선이 대신한다.
- 사진·썸네일 격자는 타일 자체가 컨테이너다. 카드로 한 번 더 감싸지 않는다.
- 회색 바탕 위 카드와 카드 없는 목록을 한 화면에 섞지 않는다. 새 일회성 카드 스타일을 만들지 않고 `FanSurface`를 쓴다.
- 제보에서 "테두리에 살짝 그림자"를 요청했으나, DESIGN.md의 카드 외곽 계약(그림자 0)과 홈 랭킹 카드(inset 1px 선)에 맞춰 헤어라인 테두리로 통일했다. 그림자로 바꾸려면 계약 변경을 함께 승인받아야 한다.

## 확인하지 못한 것

- 홈 공지 카드는 로컬 DB에 공지 데이터가 없어 임시 합성 화면(실제 `HomeNotices` 컴포넌트, 예시 3건)으로 390·1440을 확인했다. 임시 페이지는 커밋하지 않았다.
- `/my/*` 하위 일부, `/connect/*`, `/operator/*`, `/passports/[id]`, `/benefits/[id]`는 로컬 데이터가 없거나 로그인 권한이 달라 섹션 구조를 확인하지 못했다.
- 다국어 긴 문구, 키보드 초점 이동은 이번에 확인하지 않았다.
