# 웹 방송 참여와 응원 운영

홈(`/`) · 덕질(`/fandom`) · 응원(`/support`) · MY(`/my`)를 사용한다. 응원 안에 하트, 럭키드로우, 응원 기록이 있으며, 기존 팬페이지·방송·패스포트·이벤트 상세 주소는 유지한다.

## 방송 참여 공개

1. 관리자 LIVE 편집의 **방송 참여 설정**에서 실제 방송을 선택한다.
2. 참여 유형, 공개 제목·안내, 시작·마감 시각(KST)을 입력한다. 투표·퀴즈는 해당 방송의 실제 설문, 글·링크·이미지·신청곡 인증은 실제 인증 미션, 대기방은 같은 크리에이터의 공개 팬 글, 다음 방송 예약은 같은 크리에이터의 후속 방송을 연결한다.
3. **공개 목록에 표시**와 **참여 허용**을 모두 켜고 저장한다. 다른 관리자가 먼저 수정했다면 최신 내용을 다시 읽은 뒤 저장한다. 연결 원천과 유형은 기존 항목에서 바꾸지 않고 새 설정을 만든다.
4. 인증 검토에서 제출 원문·링크·이미지를 확인하고 승인 또는 보완을 요청한다. 초반·첫 입장 인증은 실제 시각과 입장 순서를 확인한다. 현재 시청자 수만으로 첫 입장을 인정하지 않는다.

배포는 가상의 방송·설문·참여 기록을 만들지 않는다. 미설정 방송은 준비 상태를 표시한다. 기존 SNS 제목·본문·사진 설명을 가져올 때는 `source-only-content.md`의 원문 보존 기준을 따른다.

## 보상과 복구

- 방송 참여는 방송별 고정 정책과 기존 포인트 원장에 기록한다. 일반 출석 적립 정책을 변경하지 않는다.
- 출석 10P, 초반 20P, 첫 입장 30P 중 최고 총액까지 차액만 지급한다. 승인 순서나 동시 요청에 따라 합계가 늘어나지 않는다.
- 재방문은 직전 방송의 유효 참여와 현재 방송의 출석·초반·첫 입장 승인 중 하나를 확인한다. 크리에이터 선정 보너스는 방송당 한 번이다.
- 같은 예약·참여를 다른 화면이나 기존 앱에서 다시 처리해도 원천과 보상을 재사용한다. 결과가 불명확한 웹 요청은 원래 요청 키·내용으로 다시 확인한다.
- 하트 교환·전송은 기존 `support-v1` 계약을 사용한다. 100P를 1하트로 교환하고 전송해도 누적 팬 점수·기여 점수는 유지한다. 내부 응원 기록은 은행 송금이나 정산 완료를 의미하지 않는다.
- 참여를 중지하려면 해당 설정의 참여 허용 또는 공개를 끈다. 이미 저장된 원천, 지급 내역, 기존 앱의 정상 참여 처리는 보존한다. 원장·접수 기록을 삭제하는 방식으로 되돌리지 않는다.

## 개인정보와 공개 현황

제출 글·링크·이미지는 본인과 권한 있는 검수 담당자만 조회한다. 인증 이미지는 장당 원본 10MB까지 받아 WebP로 정규화하며 최대 3장이다. 기존 일반 인증 업로드의 용량 제한은 유지한다. 계정 전환 시 대기 중인 토큰·업로드·제출 작업을 무효화한다.

`/pages/live-dashboard`는 공개 집계만 표시한다. DB 참여·심사와 GIWA business 집계는 서로 다른 모집단이며 각각의 상태와 시각을 표시한다. 조회 실패를 0건으로 대체하지 않는다. 개인 이름·회원 ID·지갑·인증 원문·원시 QA 거래를 공개하지 않는다.

## 배포 및 검증

`20261129009000_live_participation.sql`과 `20261129009100_celebrity_public_handle_web_navigation.sql`을 웹 배포보다 먼저 적용한다. 예약 경로 충돌이 있으면 두 번째 마이그레이션이 중단되며 기존 크리에이터 주소를 자동 변경하지 않는다.

`bash scripts/verify-live-participation.sh`는 폐기 가능한 로컬 DB에서 전체 마이그레이션, 기존 데이터가 있는 업그레이드, 권한·보상·원천 호환성, 기존/새 API 동시성을 확인한다. GitHub의 Backend security 검사에도 연결되어 있다. Fan design system 검사는 새 메뉴·참여·응원·추첨·공개 현황과 기존 패스포트 카드 계약을 검사한다.

`apps/web/e2e/web-launch-local/`는 실제 제품 컴포넌트를 합성 인증·API와 연결한 로컬 화면 검수용이다. 운영 거래나 실제 당첨 결과의 증거로 사용하지 않는다.
