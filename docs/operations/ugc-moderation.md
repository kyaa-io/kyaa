# 이용자 콘텐츠 신고 처리

앱의 게시물·댓글·메시지 신고와 사용자 차단 알림은 관리자 **신고 관리**에 모입니다. 차단은 신고자 화면에서 상대 콘텐츠를 즉시 숨기는 개인 설정이며, 차단 알림만으로 상대의 위반이나 전체 공개 중단을 확정하지 않습니다.

## 처리 기준

- 담당 운영자는 최소 12시간마다 미처리 신고를 확인합니다. 관리자 화면의 알림은 화면을 열고 있는 동안 1분마다, 다시 화면으로 돌아왔을 때 갱신됩니다. 닫힌 브라우저로 별도 알림을 보내는 기능은 아닙니다.
- 접수 시각이 오래된 신고부터 확인하며, 접수 후 24시간 이내에 판단과 필요한 조치를 마칩니다. 기한 표시만으로 실제 처리 의무가 충족되는 것은 아닙니다.
- 음란물·혐오·폭력 조장·괴롭힘 등 약관 위반이 확인되면 해당 콘텐츠를 숨기고, 관리자 권한으로 작성자의 서비스 이용을 제한합니다. 처리 사유에 확인한 위반과 조치를 구체적으로 남깁니다.
- 사용자 차단 알림은 관련 내용과 기록을 확인합니다. 차단 자체를 콘텐츠 숨김으로 처리하지 않습니다. 개별 위반 콘텐츠는 해당 콘텐츠 신고에서 숨깁니다.
- 위반이 확인되지 않으면 사유를 기록하고 반려합니다. 운영자 역할은 콘텐츠를 숨길 수 있지만 계정 이용 제한은 관리자만 할 수 있습니다.

이용 제한은 계정 삭제와 구분합니다. 기존 기록을 자동 삭제하지 않으며 본인 탈퇴 경로는 유지합니다. 텍스트 필터는 등록된 금지 표현을 검사하는 보조 수단입니다. 이미지·문맥에 대한 신고 검토를 대신하지 않습니다.

## 재심사 검증

실제 iPhone에서 로그인 전 동의, 신고, 사용자 차단과 개인 화면의 즉시 반영을 녹화합니다. 심사 답변과 심사 정보의 메모에 해당 녹화를 제공하고, 서버 배포와 앱 빌드가 실제 적용된 뒤에만 조치 완료로 설명합니다.
