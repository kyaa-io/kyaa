- 공지 상세 경로 `/notices/tier-guide`: 기존 공지 상세와 동일한 제목·본문 역할을 사용한다.
- 실제 확인한 정책의 11단계, 획득 조건만 기록한다. 확정되지 않은 등급 혜택은 표시하지 않는다.
- 승인된 ink-v1 등급 도장 11종을 그대로 사용한다. Codex imagegen으로 만든 분홍 여권·하트 도장 보조 그림은 정보나 혜택을 암시하지 않는 장식이며 1200×800 자연 비율을 유지한다.
- 팬 활동 기록과 MY 등급 이름 옆에서 공통 정보 버튼 → FanDialog → 안내로 이동한다. 설명용 보조 줄을 추가하지 않는다.
- 모든 12개 언어, 키보드 열기·닫기·초점 복귀, 44px 터치 영역, 가로 넘침을 검증한다.
- 로컬 실제 컴포넌트 + 예시 데이터의 390·1440 브라우저 캡처를 남기며 운영 화면으로 표현하지 않는다.
- 타입검사 및 관련 vitest, 실제 브라우저 동작과 이미지 원본/표시 비율을 확인한 뒤 커밋한다. 푸시하지 않는다.

새 임의 디자인 값은 도입하지 않고 기존 역할 토큰을 사용한다. 원본 그림은 Codex imagegen 기본 저장 위치에 보존하고 웹용 WebP만 저장소에 넣는다.
