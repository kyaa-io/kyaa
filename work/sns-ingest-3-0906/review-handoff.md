# SNS-INGEST-3-0906 재검토 인계

현재 브랜치에는 배정 설명과 달리 ingest 코드가 없어 t3/sns-ingest-2를 merge했다.
다운로드 실제 fetch의 동일 호스트/외부 redirect 차단, 길이 누락/거짓/잘못된 헤더·8MiB 초과 stream 취소, 정확히 8MiB 허용, 비정상 응답을 시험한다. sharp 실제 JPEG/PNG/WebP 처리 및 손상/SVG/다중 페이지/4천만 픽셀 초과 거절을 시험한다. 잘못된 길이 헤더도 취소·거절한다.
인증·입력·등록 출처 거절은 비밀과 본문 없이 서버 로그로 기록한다. DB 실행 감사는 begin_run 이후만이며 문서에 구분했다. 상한은 HTTP 요청별 5건이며 collector 전체 합산 상한은 아니다. 기존 미공개 artist_post 초안 복구의 실제 SQL 범위를 문서에 맞췄다. 기존 migration은 수정하지 않았다.
결정 1: 관리자 로그인/자동화 운영 설정은 변경하지 않았다. 결정 2: 승인된 dev 보완 구현. 결정 3: 기존 사진별 화면 검수 유지(안전 기본값); 자동 검사로 대체하지 않는다. 독립 검토는 감독 담당이며 통합·운영 활성화는 하지 않았다.

pending-candidates.json은 76건을 현재 시각 기준으로 분류한 목록이다. 71건은 날짜 조건 내 재확인 후보, 5건은 제외다. 원문·공식계정 현재 등록 상태·새벽 146건 공개와의 중복 재확인은 하지 않았으므로 즉시 공개 가능 확정 목록이 아니다. 사진의 기존 시각 검수도 남아 있다.

SQL 및 local DB 시험은 DB 환경 미설정으로 미실행이다. 실제 CDN 호출 없이 로컬 HTTP redirect와 fetch 응답 stream 및 sharp를 시험했다. 비밀 설정·운영 CMS 활성화는 하지 않았다.
