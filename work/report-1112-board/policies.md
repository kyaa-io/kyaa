# B4 표시 정책

1. 추천: 조회수 < 추천수인 글의 조회수만 숨긴다. 나머지 글의 실제 조회수와 모든 추천수는 유지한다. 공통 FanPostRow와 PostDetailHeader에 구현했다. 비교 불가능한 과거 수치만 감추지만 조회수 수집 전후의 의미 차이가 완전히 해소되는 것은 아니다.
2. 대안: 게시판 전체에서 조회수 표시를 없앤다. 일관되지만 정상적으로 집계한 글의 조회수도 사라진다. 적용 시 FanPostRow의 조회수 셀은 빈 셀로 유지하고 PostDetailHeader의 조회수 span을 제거한다. 현재 코드는 1안을 사용한다.

max(조회수, 추천수)는 실제 조회 기록을 넘어선 숫자를 만들므로 채택하지 않았다. 집계·추천·원장 데이터 보정은 없다.
