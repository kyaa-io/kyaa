## 실행

표가 있을 때 릴리스가 운영 대장 순서로 한다. 순서: 마이그레이션 → doc-14 `load-14.sql`(엘리나가 있어야 한다) → 이 시드. `--apply`가 없으면 신원과 권한만 확인하고 쓰지 않는다.

```sh
node scripts/seed-doc-261107-dev.mjs --config <비공개 설정> --confirm-dev SEED_DOC_261107_DEV_ONLY --op seed --viewer-email <시험 계정> [--apply]
... --op presence=online|today|off --apply   # online은 2시간 유지
... --op gauge=37 --apply                    # 0이면 값을 지운다
... --op list                                # 읽기만 한다. 정리 전 기록용
... --op cleanup --apply                     # DB 정리 후 저장소 파일 삭제
```

설정 파일은 `seed-groups-pencil-dev.mjs`와 같고 `privateBucket`이 더 있다(이름에 `dev`). 시험 계정 메일은 저장소에 넣지 않는다.

`--op cleanup --apply`가 모두 지운다. 한 트랜잭션이고 문제가 있으면 전부 되돌린다.
