# KYAA Stage Console

Mac에서 공연 출력 창을 띄우고 같은 네트워크의 iPad Safari에서 조작하는 로컬 앱입니다. 원본 발표 자료와 관리자 인증은 별도로 보존합니다.

## 실행

패키지 `KYAA Stage.app`을 엽니다. 연결 설정에서 관객용 디스플레이를 선택합니다. 디스플레이가 하나면 선택 후 같은 Mac에서 출력 창과 조작 창을 전환할 수 있습니다. HDMI가 빠지면 출력 창을 숨기고 Mac 조작은 유지합니다.

iPad를 Mac과 같은 Wi-Fi 또는 개인 핫스폿에 연결합니다. Mac 연결 설정의 인증서 다운로드 주소를 iPad Safari에서 열어 로컬 인증서를 설치하고, iPad 설정 → 일반 → 정보 → 인증서 신뢰 설정에서 해당 인증서를 신뢰합니다. 설치 전에 iPad 인증서 세부 정보의 SHA-256 지문을 Mac 연결 설정에 표시된 값과 대조합니다. 이어 페어링 QR을 스캔합니다. 주소는 실행할 때마다 바뀌며 다른 사람에게 공유하지 않습니다. 브라우저의 인증서 경고를 우회하지 않습니다. 행사 후에는 iPad의 해당 인증서 프로파일을 삭제할 수 있습니다.

네트워크가 불안정하면 Mac 조작 창에서 그대로 다음 큐를 진행합니다. 별도 공유기나 핫스폿으로 바꾸면 새 연결 주소와 QR이 표시됩니다. iPad를 다시 연결해 현재 상태를 받은 뒤 조작합니다. 끊긴 동안의 터치는 재전송하지 않습니다. 앱 재실행 시 마지막 큐로 돌아오되 영상은 일시정지합니다.

## 데이터 연결

이 브랜치의 웹 연결 기능을 실행 중인 로컬 웹 서버 주소를 Mac의 ‘데이터 원본 주소’에 입력합니다(예: `http://localhost:3000`). ‘데이터 원본 브라우저 열기’를 눌러 기존 브라우저에서 로그인한 뒤 화면의 연결 버튼을 누릅니다. 운영 사이트에서는 연결 기능이 별도 배포된 뒤 사용할 수 있습니다. 현재 구현은 운영에 배포하지 않았습니다.

브라우저는 집계와 공개된 결과만 Mac에 전송합니다. 인증 쿠키·토큰·내부 회원 ID는 복사하지 않습니다. 추첨 실행은 기존 관리자 화면에서 직접 확인합니다. iPad의 추첨·결과 화면은 조회용입니다.

## 공연과 음향

큐는 수동으로 전환하며 37초 인트로가 정상 종료될 때만 다음 발표 큐로 넘어갑니다. 출력이 연결된 상태에서 영상·HTML 큐를 선택하면 영상이 자동 재생됩니다. 공연 중 영상 재생·일시정지·처음부터 버튼을 사용할 수 있습니다. LIVE 화면에는 독립된 TikTok 웹 화면을 띄웁니다. TikTok의 로그인·재생 허용·방송 종료 상태는 외부 서비스에 따라 달라지므로 행사 전 실제 생방송으로 확인해야 합니다. 오디오는 선택한 한 방송만 켭니다.

공연 파일 변경은 `scripts/README.md`의 변환 명령으로 새로운 show 폴더를 생성한 뒤 ‘공연 파일 가져오기’로 선택합니다. 앱은 새 폴더로 재시작합니다. 기존 파일을 덮어쓰지 않습니다.

웹 배포에 Electron 설치가 포함되지 않도록 이 앱은 루트 npm workspace에서 제외되어 있습니다. 아래 명령은 `apps/stage-console`에서 실행합니다.

## 개발 검증

```sh
npm install --workspaces=false
npm test
node --test src/protocol.test.mjs
python3 -m unittest discover -s scripts -p 'test_*.py'
npm run build
KYAA_SHOW=/absolute/show npm start
node scripts/package-mac.mjs '/absolute/KYAA Stage.app' /absolute/show
```

실제 iPad 인증서 설치·HDMI·현장 음향·동시 생방송은 현장 리허설이 필요합니다. 앱은 로컬 서명이며 Apple 공증 배포본이 아닙니다.
