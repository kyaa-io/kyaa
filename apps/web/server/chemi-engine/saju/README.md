# 사주 계산 계약

서버 전용 순수 함수 `calculateSaju`가 원국과 고정표 선택 키를 반환한다. DB·네트워크·환경값은 읽지 않는다. `manseryeok@2.0.0`(MIT), 시험 전용 `lunar-javascript@1.7.7`(MIT)가 필요하다. 감독이 위임한 의존성 범위에 따라 apps/web/package.json과 루트 package-lock.json에 정확한 버전을 고정했다.

자시는 진태양시 보정 **후** 23시부터 다음 날이다. 서울 126.978도 경도 보정 -32.088분에 균시차 및 역사적 표준시·서머타임 보정을 함께 적용한다. 절입 순간은 태양시로 옮기지 않는다. 12신살은 연지 삼합 기준이며 지장간은 본기 우선이다. 십신은 고정한 엔진 관법을 따른다.

시간 모름은 정오로 날짜 유효성 및 일주를 계산하고 시주·대운을 반환하지 않는다. 절입 당일이면 월주와 이에 의존하는 성격·오행·대운·직업 주제를 잠근다. 입춘이면 연주도 확정하지 않는다. 돈 주제는 잠금 목록에 넣지 않는다. 잠금은 표시 UI가 아닌 소비자를 위한 데이터다.

검증 범위: 현대 정오 생일 40건의 4기둥을 독립 엔진과 대조한다. 보정 자시 인접 분(23:42·23:43), 입춘·경칩 절입 1분 전후의 고정 기대값과 독립 엔진 대조, 서울 보정·입춘 시간 모름·잘못된 날짜·대표 고정표를 별도로 시험한다. 이 40건은 KASI 원본 1900–2030 전체나 외부 서비스 6곳의 대조를 대체하지 않는다. 패키지 내 정밀 절기/KASI 데이터를 쓰지만 별도 공공데이터 API 원본 수집은 포함하지 않는다.
